Software Final

Intelligent Tic Tac Toe

Intelligent Tic Tac Toe is a C++ application that allows a user to compete against an AI-powered opponent. Instead of relying only on random moves or simple preset logic, this project uses a locally hosted AI model through Ollama to help choose moves during gameplay.

Technical Stack

C++, Ollama, local AI models, curl requests, JSON response handling, vectors, loops, conditionals, and functions.

Process & Challenges

I designed the game by separating the board display, win checking, player input, and AI move selection into different parts of the program. One of the main challenges was reading the AI response correctly and making sure the program could reject invalid moves.

Sample Code
if (checkWin(board, 'X')) {
    cout << "You win!" << endl;
}

Earth Prize / Biomimicry Challenge

Smart Compost Dispenser Prototype

The Smart Compost Dispenser was developed as part of the Earth Prize and Biomimicry Challenge. The project focuses on improving compost management by using sensor-based monitoring and an automated dispenser concept to help maintain better composting conditions.

Technical Stack

Arduino Uno, soil moisture and temperature sensors, servo motors, Tinkercad 3D modeling, circuit planning, prototype diagrams, and presentation slides.

Process & Challenges

I worked through different prototype ideas to decide how the dispenser could attach to different compost bin sizes. A major challenge was planning how the sensor, wiring, Arduino, refillable sections, and moving parts would fit together in a practical design.

Python Image Processing

Profile Picture Image Generator

The Profile Picture Image Generator is a Python application that retrieves a random image from an online API and transforms it into a formatted profile picture. The program resizes the image, applies a custom filter, and saves the finished result as a new image file.

Technical Stack

Python, requests library, Pillow/PIL, Dog CEO image API, image resizing, file saving, and pixel editing.

Process & Challenges

I organized the program into separate steps for downloading, editing, and saving the image. The main challenge was learning how RGB pixel values work and making sure the edited color values stayed within the correct range.

Sample Code
for x in range(width):
    for y in range(height):
        r, g, b = pixels[x, y]
        r = min(r + 50, 255)
        pixels[x, y] = (r, g, b)

AP CSP Create Performance Task

Basketball Performance Score Calculator

The Basketball Performance Score Calculator was developed for the AP Computer Science Principles Create Performance Task. The application collects a player's points, assists, and rebounds, then calculates a standardized performance score that can be used to compare basketball performances.

Technical Stack

Python, lists, functions with parameters, loops, conditionals, user input, score calculation, and file handling.

Process & Challenges

I created a scoring system that combines multiple basketball statistics into one overall number. The main challenge was designing a formula that made sense while also storing each player's result so scores could be reviewed and compared later.

Sample Code
score = (points * 2) + (assists * 3) + rebounds
